# README – Styleguide HvanA Website
Over dit project

Voor de website van de HvanA hebben Rayhana, Loïs en Kennie een styleguide opgesteld. Deze styleguide zorgt voor een consistente en overzichtelijke vormgeving binnen de website en biedt een centrale plek waar alle ontwerpregels zijn vastgelegd.

De styleguide bevat verschillende ontwerpcomponenten die als basis dienen voor de ontwikkeling van de website.

Inhoud van de Styleguide

De volgende onderdelen zijn opgenomen:

- Kleuren
- Typografie
- Formulieren
- Grid-systeem
- Spacing

## Kleuren

De kleuren zijn gedefinieerd met behulp van het HSL-kleurmodel (Hue, Saturation, Lightness). Hierdoor kunnen kleuren eenvoudig worden aangepast en blijven kleurrelaties consistent binnen het ontwerp.

## Typografie

De typografie-richtlijnen beschrijven het gebruik van:

- Lettertypes
- Font-sized
- Regellengte

Hierdoor ontstaat een duidelijke en consistente leeservaring voor gebruikers.

## Formulieren

- Inputvelden
- Checkboxes
- Knoppen

## Grid

Het grid-systeem vormt de basis van de lay-out en helpt bij het consistent uitlijnen van content. Door gebruik te maken van een vaste structuur blijft de website overzichtelijk en responsief op verschillende schermformaten.

## Spacing

Voor marges en paddings zijn vaste spacing-waarden gedefinieerd. Deze waarden zijn vastgelegd als custom properties zodat afstanden overal binnen het project consistent blijven.
